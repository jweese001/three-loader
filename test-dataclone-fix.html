🔧 DataCloneError Fix Applied

Issue Resolved: Worker message passing failure with function serialization

✅ Fix Applied

Problem: CodeCompiler was passing helper functions in context to CodeSandbox worker, but functions cannot be serialized via postMessage (DataCloneError).

Root Cause: The error "Failed to execute 'postMessage' on 'Worker': (degrees) => degrees * (Math.PI / 180) could not be cloned" occurred because helper functions in context cannot be transferred between main thread and web worker.

Solution: Moved helper functions from CodeCompiler context to CodeSandbox worker's internal execution context.

Result: Context is now serializable and functions are available in worker environment.
