🧪 Test Procedure

Follow these steps to verify the complete centralized asset management workflow:

Step 1: Initial Setup

1. Click "Open 3Loader Application" button above

2. Open Browser DevTools (F12) and switch to Console tab

Expected: Project dialog should appear asking for folder setup

Step 2: Project Folder Setup

1. In the project dialog, click "Create New Project" or "Browse Folder"

2. Select or create "3Loader-Projects" folder in your Documents directory

Expected: Console shows "✅ Project initialized successfully"

Console Output: 📁 Initializing 3Loader project structure... 📂 Project folders created/verified: {textures: "textures", models: "models", ...} ✅ Project initialized successfully

Step 3: Load OBJ File with Auto-Copy

1. In the "Load Objects" panel, click "Browse OBJ Files"

2. Select any .obj file from anywhere on your system

Expected: File automatically copied to project folder with UUID naming

Console Output: 📁 Processing file: example.obj 📋 Copying OBJ file to project folder... ✅ OBJ file copied to project: {storedPath: "./models/uuid-example.obj"} ✅ File loaded successfully: example.obj

Step 4: Apply Texture with Auto-Copy

1. Select the loaded object in the Objects list

2. In Material panel, click texture "Load" button

3. Select any texture file (.webp, .jpg, .png) from anywhere on system

Expected: Texture automatically copied to project folder

Console Output: 🎨 Processing texture file selection: example.webp 📋 Copying texture to project folder... ✅ Texture copied to project: {storedPath: "./textures/uuid-example.webp"}

Step 5: Code Generation with Project Paths

1. Click "Code View" to switch to code editor

2. Click "From UI" button to generate code

Expected: Generated code uses project-relative paths

Generated Code Should Show: // OBJ file loading with project path fileName: './models/uuid-example.obj', // Texture loading with project path const texture = new THREE.TextureLoader().load('./textures/uuid-example.webp');

Step 6: Verify Project Folder Structure

1. Open Finder/File Explorer

2. Navigate to ~/Documents/3Loader-Projects/

Expected: Organized folder structure with copied assets

3Loader-Projects/ ├── models/ # UUID-named OBJ files │ └── uuid-example.obj ├── textures/ # UUID-named texture files │ └── uuid-example.webp ├── projects/ # Future: saved project files ├── exports/ # Future: standalone project exports └── temp/ # Temporary files

  • ❌ Unsupported: Firefox, Safari (fallback with user notification)

Common Issues:

  • "Must be handling a user gesture" - Fixed! Project setup now happens on button click
  • Second attempt fails - Fixed! File inputs are properly reset on errors
  • Inconsistent behavior - Fixed! Clear separation between setup and file processing
  • Dialog doesn't appear again - By design! Project persists for 7 days (configurable)
