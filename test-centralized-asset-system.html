🧪 Testing Instructions

  1. Load an object:
    • Primitive: Select from dropdown (sphere, box, etc.) and click "Load Primitive"
    • OBJ File: Click "Browse OBJ Files" and select a .obj file
  2. Select any material type (Standard, Physical, Basic, Lambert, Phong, MatCap)
  3. Click texture "Load" button
  4. First time only: Browser will ask for folder permission - select or create "3Loader-Projects" in your Documents folder
  5. Select any texture file from anywhere on your system (.webp, .jpg, .png)
  6. Click "From UI" button to generate code
  7. Verify generated code shows reliable path: ./textures/uuid-filename.ext

🛠️ Troubleshooting

Common Issues & Fixes:

❌ "Must be handling a user gesture to show a file picker"

  • Cause: Browser security requires direct user interaction for folder picker
  • Fix: ✅ Fixed! Project setup now happens on button click (direct user gesture)

❌ Second attempt doesn't work / no response

  • Cause: Error state not properly reset
  • Fix: ✅ Fixed! File input is now reset on errors

❌ Inconsistent behavior on repeated attempts

  • Cause: Project initialization mixed with file processing
  • Fix: ✅ Fixed! Clear separation: setup on button click, processing on file selection
