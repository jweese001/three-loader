🎯 User Custom Textures

The fix also supports users' custom texture organization:

  • If webkitRelativePath is available: Uses complete folder structure
  • If not available: Falls back to filename only (for single files)
  • Works with any folder organization, not just MatCap collections

✅ This addresses the user's concern: "that might work for the matcaps but that's going to be hard to do if a user has their own file system for textures they own"
